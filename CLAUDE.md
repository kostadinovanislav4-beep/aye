# AYE — правила за работа

Лично PWA за подготовка за ДЗИ по БЕЛ и Cambridge C1 Advanced (CAE). Единствен потребител: ученик в 12. клас. Основно устройство: iPhone със Safari (инсталирано PWA); второ — лаптоп с Windows.

- Пълното задание е в `SPEC.md` — чети го при нужда. Ако чатът противоречи на SPEC, чатът има предимство, но питай дали да обновим SPEC.
- ДЗИ по БЕЛ: 19.05.2027 г., 08:30 ч. (заповед № РД09-3343/31.08.2026 г., виж `content/SOURCES.md`). Датата на CAE още не е известна.

## Фази

Текуща фаза: **0 — завършена на 25.09.2026** (чака само проверка на iPhone). Следва **1 — Двигател**: първо предложи схемата на прогреса (Dexie) за одобрение.

0 план и скеле · 1 двигател · 2 БЕЛ съдържание v1 · 3 CAE съдържание v1 · 4 практика и симулатор · 5 писане, слушане, говорене · 6 планер, аналитика, режими · 7 съдържание до минимумите · 8 шлифоване.

- Не прескачай напред. Нова фаза започва, когато предишната е затворена.
- Затваряне на фаза: `lint`, `test`, `validate:content` и `build` минават → commit → запис в `CHANGELOG.md` → един абзац към потребителя (готово / решено / предстои). Обнови „Текуща фаза“ тук.
- Питай само за трудно обратими решения: модел на данните, формат на съдържанието, схема на прогреса. Останалото решавай сам и казвай накратко.
- Push към `main` публикува сайта — питай потребителя преди push.

## Среда (Windows)

- Node.js 24, Git и GitHub CLI са преносими версии в `D:\tools\node`, `D:\tools\git` и `D:\tools\gh` и **не са** в системния PATH. В PowerShell започвай командите с:
  `$env:Path = 'D:\tools\node;D:\tools\git\cmd;D:\tools\gh\bin;' + $env:Path`
- Ползвай `npm.cmd` и `npx.cmd` (PowerShell може да блокира `npm.ps1`).
- Проектът е в `D:\aye`. Repo: https://github.com/kostadinovanislav4-beep/aye. Сайтът: https://kostadinovanislav4-beep.github.io/aye/.
- `gh` е влязъл като `kostadinovanislav4-beep` (токенът е в Windows Credential Manager). Само в това repo git взима достъпа от `gh auth git-credential` (`.git/config`). Commit-ите са с noreply адреса от GitHub (локален `user.email`).
- Резултата от deploy следи с `gh run watch` (repo `kostadinovanislav4-beep/aye`).

## Стек

Vite 8, React 18.3 (фиксиран в SPEC), TypeScript 6.0, Tailwind CSS 4 (изисква iOS 16.4+), react-router-dom 7 с адреси с `#`, zustand 5, Dexie 4, zod 4, vite-plugin-pwa 1, lucide-react, Vitest 5, ESLint 9, Prettier. FSRS: `ts-fsrs` (от Фаза 1).

- TypeScript 7 и ESLint 10 още не се поддържат от typescript-eslint и eslint-plugin-jsx-a11y. Не ъпгрейдвай мажорни версии без проверка на съвместимостта.

## Код

- `src/domain/` — чиста логика без React и без DOM (типовете се проверяват и в Node проекта). `src/data/` — Dexie и localStorage. `src/features/<модул>/` — екрани. `src/components/` — общи компоненти. `src/app/` — обвивка, навигация, маршрути, PWA.
- TypeScript `strict` и `noUncheckedIndexedAccess`; без `any`. Малки компоненти. Простият код е за предпочитане пред „умния“.
- Тестове (Vitest) за цялата домейн логика: оценители, планировчик, валидатор, миграции, генератор на варианти.
- Всички GitHub Pages сайтове на потребителя споделят един origin, затова базата и ключовете в localStorage започват с `aye`.
- localStorage само за настройки (`aye:settings`). Прогресът е в IndexedDB (Dexie, от Фаза 1). Нищо не се изпраща навън.

## Интерфейс

- Само на български. Правописът и пунктуацията са безупречни — потребителят се готви за изпит по тях. Преди затваряне на фаза прегледай новите низове.
- Текстовете са неутрални по род (без „готов/готова“, „дошъл/дошла“). Обръщение на „ти“.
- Светла тема по подразбиране със светлосиньо; тъмната е по избор. Цветовете са токени в `src/styles/index.css`: `bg`, `surface`, `surface-2`, `border`, `text`, `muted`, `accent`, `accent-soft`, `accent-strong`, `on-accent`, `focus`. Светлосиньото (`accent`) е за фонове и акценти; текст и икони върху светъл фон са в `accent-strong` (контраст ≥ 4.5:1).
- Mobile-first: долна навигация, бутоните за оценка — долу, зони за натискане ≥ 44 px, отстъп за долната системна линия (`pb-safe`).
- Достъпност: видим фокус, `aria-*` където трябва, работа с клавиатура.

## Съдържание (най-важното)

- Вярност: цитати само от текста на произведението, никога по памет. При съмнение — не включвай или `"verified": false`. Факти за изпитите — само от mon.bg и cambridgeenglish.org, записани в `content/SOURCES.md`.
- Авторски права: пълни текстове само за автори, починали преди 1956 г. (Ботев, Вазов, Алеко Константинов, П. П. Славейков, Яворов, Елин Пелин, Дебелянов, Смирненски, Гео Милев, Йовков, Вапцаров) — от chitanka.info, в `content/bel/texts/`. За останалите — кратки цитати (1–3 изречения или стиха), резюме и анализ със свои думи, линк.
- CAE текстовете са оригинални, в стила на изпита. Не се копират материали на Cambridge.
- Форматът е в `content/README.md` (одобрен във Фаза 0), схемите — в `src/domain/content/schema.ts`. Тагове само от `content/tags.json`, критерии — от `content/rubrics.json`.
- Колода = файл `content/<изпит>/<област>/<тема>.json` с около 50 елемента. id на елемент не се сменя никога.
- Нови елементи: прочети `content/README.md` → нов файл в правилната папка → `npm run validate:content` и `npm run test` → отбележи непроверените → commit → кажи колко и какво е добавено. Подагенти може, но всичко минава през валидатора.
- Трудност ≈ 20/30/30/15/5 % за нива 1–5. Качество пред количество.

## Deploy

GitHub Actions (`.github/workflows/deploy.yml`) при push към `main`: lint → test → validate:content → build → GitHub Pages. `base` е `/aye/` (`vite.config.ts`).
