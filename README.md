# AYE

Лично приложение за подготовка за ДЗИ по български език и литература и за Cambridge C1 Advanced. Работи офлайн, инсталира се на телефона, а всички данни стоят на устройството.

- Приложението: https://kostadinovanislav4-beep.github.io/aye/
- Заданието: [SPEC.md](SPEC.md) · Правилата за Claude: [CLAUDE.md](CLAUDE.md) · Промени: [CHANGELOG.md](CHANGELOG.md) · Съдържание: [content/README.md](content/README.md)

## Инсталиране на iPhone

1. Отвори адреса на приложението в Safari.
2. Натисни бутона за споделяне и избери добавяне към началния екран.
3. Отваряй AYE от иконата. Така работи и без интернет, а iOS не изтрива данните му, когато не си го отваряш няколко дни.

## Стартиране на лаптопа

Нужни са Node.js 24 и Git. На този компютър те са преносими версии в `D:\tools` и не са в системния PATH. В PowerShell:

```powershell
$env:Path = 'D:\tools\node;D:\tools\git\cmd;' + $env:Path
cd D:\aye
npm.cmd install
npm.cmd run dev
```

После отвори `http://localhost:5173/aye/`. Ако PowerShell откаже да пусне `npm`, пиши `npm.cmd`, както по-горе.

За преглед на телефона в същата Wi-Fi мрежа пусни `npm.cmd run dev:host` и отвори адреса от реда „Network“. Така не работят офлайн режимът и инсталирането — за тях ползвай адреса в GitHub Pages.

## Команди

| Команда                    | Какво прави                           |
| -------------------------- | ------------------------------------- |
| `npm run dev`              | локален сървър                        |
| `npm run build`            | проверка на типовете и билд в `dist/` |
| `npm run preview`          | преглед на билда                      |
| `npm run lint`             | проверка на кода и форматирането      |
| `npm run format`           | форматира кода                        |
| `npm run test`             | тестове                               |
| `npm run validate:content` | проверка на съдържанието в `content/` |
| `npm run icons`            | генерира иконите в `public/`          |

## Deploy

При всеки push към `main` GitHub Actions пуска проверките (lint, тестове, валидатор, build) и публикува приложението в GitHub Pages. Ако някоя проверка падне, публикуване няма.

Еднократна настройка в GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Бекъп

Всички данни са само на устройството: прогресът е в IndexedDB (базата `aye`), а настройките — в localStorage (`aye:settings`). Бекъпът е един JSON файл с всичко това.

- **Направи бекъп:** Настройки → Бекъп → „Направи бекъп“. На iPhone се отваря менюто за споделяне — избери „Запази във Файлове“ или изпрати файла на себе си. На лаптопа файлът се изтегля като `aye-backup-ГГГГ-ММ-ДД.json`.
- **Възстанови или пренеси:** Настройки → Бекъп → „Импортирай“ и избери файла. Импортът слива данните с тези на устройството и не изтрива нищо, затова може да се пуска повече от веднъж.
- Таблото напомня за бекъп веднъж седмично.

Инсталираното приложение на iPhone има отделно хранилище от Safari. Ако преминеш от единия към другия, пренеси данните с бекъп.
