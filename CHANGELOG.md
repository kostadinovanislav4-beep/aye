# Промени

Всяка фаза от SPEC добавя минорна версия: Фаза 0 е 0.1.0, Фаза 1 — 0.2.0 и т.н.

## [0.1.0] — 2026-09-24 — Фаза 0: план и скеле

### Добавено

- Проект с Vite 8, React 18.3, TypeScript 6 (strict), Tailwind CSS 4, react-router-dom 7, zustand, Dexie, zod, vite-plugin-pwa.
- Празно приложение с навигация между всички модули: долна лента на телефона, странично меню на лаптопа, екран „Още“.
- Светла тема по подразбиране със светлосиньо и тъмна тема по избор (Настройки).
- PWA: manifest на български, икони, офлайн кеш, бутон „Обнови“ при нова версия, подсказка за инсталиране на iPhone.
- Схеми (zod) за всички 13 типа елементи, валидатор `npm run validate:content`, `content/README.md` с проверени примери, `content/tags.json` и `content/rubrics.json`.
- Тестове (Vitest) за нормализирането на отговори, маркерите, схемите, валидатора, темата и разпознаването на iOS.
- Deploy в GitHub Pages чрез GitHub Actions.
- `CLAUDE.md`, `README.md`, `content/SOURCES.md`.

### Решения

- Датата на ДЗИ по БЕЛ (19.05.2027 г., 08:30 ч.) е сверена със заповедта на МОН.
- Нов тип `mc_cloze` за CAE Reading and Use of English част 1 — липсваше в SPEC.
- Грешките в `edit_text` се задават с фрагмент от текста, а позициите се изчисляват автоматично.
- Адресите са с `#`, за да работят в GitHub Pages и офлайн.
- Светла тема по подразбиране (SPEC е обновен).
- TypeScript 6.0 и ESLint 9 вместо най-новите 7 и 10 — заради съвместимостта на плъгините.
