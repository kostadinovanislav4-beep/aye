## 2. Технически решения (фиксирани)

**Тип:** PWA (progressive web app) — уеб приложение, което се инсталира на началния екран на телефона и работи офлайн.

**Стек:**
- Vite + React 18 + TypeScript (`strict: true`)
- Tailwind CSS; без тежки UI библиотеки. Иконки: `lucide-react`.
- Routing: `react-router-dom`
- State: `zustand` (малко и просто). Домейн логиката е извън React (`src/domain/`).
- Съхранение: IndexedDB чрез `dexie` с версионирани миграции. `localStorage` само за настройки.
- Spaced repetition: `ts-fsrs` (алгоритъм FSRS). Не пиши собствен SM-2.
- Валидация на данни и съдържание: `zod`
- PWA: `vite-plugin-pwa` (Workbox), offline-first, manifest, икони, подсказка „Инсталирай“.
- Реч: Web Speech API — `speechSynthesis` (слушане, произношение) и `SpeechRecognition` (говорене). Записи: `MediaRecorder`. Всичко с feature detection и резервен вариант.
- Тестове: `vitest` за домейн логиката (планировчик, оценители, валидатори, миграции). По желание един smoke тест с Playwright.
- Качество: ESLint + Prettier.
- Deploy: GitHub Pages чрез GitHub Actions (`.github/workflows/deploy.yml`, `actions/deploy-pages`); `base` във `vite.config.ts` = името на repo-то. Cloudflare Pages/Netlify са също безплатни, но по подразбиране — GitHub Pages.

**Забранено:** бекенд, облачни бази, платени услуги, аналитика/трекинг, акаунти, изпращане на моите данни навън.

**Съхранение на данните:**
- Всичко е на устройството. При първо стартиране извикай `navigator.storage.persist()`.
- Експорт/импорт на цялата база (прогрес + настройки + мои текстове) в един JSON файл. Импортът прави merge по id и timestamp, не презаписва сляпо.
- Седмично напомняне „Направи бекъп“ в приложението.
- Обновяване на приложението никога не губи прогрес. Миграциите в Dexie имат тестове.

## 3. Правила за съдържанието (най-важният раздел)

### 3.1 Вярност
- Цитатите от произведения са точни, дума по дума. Взимаш ги от текста на произведението, не по памет. Ако нямаш текста — не измисляй цитат.
- Всяка задача има: верен отговор, обяснение защо е верен, за MCQ — защо всяка грешна алтернатива е грешна, тагове, трудност (1–5), източник или правило.
- Всеки елемент има поле `verified: boolean`. Всичко, което не е проверено по източник, е `false` и се показва в екран „За проверка“ в приложението, за да го прегледам аз.
- Фактите за изпитните формати се проверяват в официалните източници (`mon.bg` за ДЗИ, `cambridgeenglish.org` за CAE) преди Фаза 4. Записваш използваните източници и датата в `content/SOURCES.md`.

### 3.2 Авторски права
- Пълни текстове на произведения включваш само за автори с изтекли права (в България — 70 г. след смъртта на автора; през 2026 г. това са авторите, починали преди 1956 г.: Ботев, Вазов, Алеко Константинов, П. П. Славейков, Яворов, Елин Пелин, Дебелянов, Смирненски, Гео Милев, Йовков, Вапцаров). Източник: Моята библиотека (chitanka.info). Съхраняваш ги в `content/bel/texts/`.
- За останалите (Далчев, Багряна, Димов, Талев, Радичков и др.) — само кратки цитати (1–3 изречения или стиха), резюме и анализ със свои думи, плюс линк към текста. Без пълни текстове.
- CAE текстовете (reading, скриптове за listening) пишеш ти — оригинални, в стила на изпита. Не копираш реални изпитни материали на Cambridge.

### 3.3 Език
- Интерфейсът е на български. Съдържанието за БЕЛ е на български. Съдържанието за CAE е на английски; инструкциите към мен може да са на български.
- Правописът на всеки текст в интерфейса е безупречен — аз се готвя за изпит по правопис. Преди затваряне на всяка фаза прегледай новите UI низове за грешки.

### 3.4 Формат и организация
- Съдържанието живее само в `content/` (не в компонентите), като JSON файлове по ~50 елемента, групирани по изпит/област/тема.
- Схемите на всички типове са в `src/domain/content/schema.ts` (zod) и са документирани с примери в `content/README.md`. Така в бъдещи сесии мога да казвам „добави 50 задачи за пунктуация“, а ти да ги добавяш в същия формат.
- `npm run validate:content` проверява: схема, уникални id, дублирани условия (нормализирано сравнение), точно един верен отговор при MCQ, разпределение на трудността, наличие на обяснение, тагове само от `content/tags.json`.
- При build съдържанието се компилира в chunk-ове, които се зареждат lazily по колода.

### 3.5 Работен процес за добавяне на съдържание (за бъдещи сесии)
Когато поискам ново съдържание: прочети `content/README.md` → напиши елементите в нов файл в правилната папка → пусни валидатора и тестовете → отбележи непроверените елементи → commit → кажи ми колко и какво е добавено. За големи обеми може да ползваш подагенти паралелно по области, но всеки резултат минава през валидатора.

## 4. Модел на данните

### 4.1 Типове елементи
Общи полета: `id`, `type`, `exam: "bel" | "cae"`, `tags[]`, `difficulty` (1–5), `explanation`, `source?`, `verified`.

- `basic` — лице/гръб, незадължителна подсказка.
- `cloze` — текст с `{{c1::скрито}}`, няколко изтривания; използва се и за цитати.
- `mcq` — условие, 4–5 отговора, индекс на верния, обяснение за всеки дистрактор.
- `short` — кратък свободен отговор; масив от приети отговори + правила за нормализация (регистър, интервали, пунктуация, незадължителен regex).
- `edit_text` — текст с грешки (БЕЛ: редактиране); списък от грешки с позиция и приети поправки.
- `text_set` — текст + въпроси (БЕЛ „работа с текст“; CAE Reading части 5–8: multiple choice, cross-text matching, gapped text, multiple matching).
- `open_cloze` — CAE част 2.
- `word_formation` — CAE част 3: текст с празни места + коренна дума + приети форми.
- `kwt` — CAE част 4: изречение, ключова дума, второ изречение с празно място, приети отговори (3–6 думи); точкуване 0/1/2 както на изпита.
- `listening_set` — скрипт(ове) с говорители за TTS (език, глас, темпо), въпроси, колко пъти се чува, транскрипт след края.
- `speaking_task` — част 1–4, въпроси и сцени (описани с текст или прост SVG), таймери, примерни отговори, полезни фрази.
- `writing_task` — тип текст, задание, целеви обем, критерии за оценяване, чеклист, примерен отговор с анотации, банка с фрази.

### 4.2 Прогрес (Dexie таблици)
- `cards` — състояние по FSRS: due, stability, difficulty, reps, lapses, state, last_review.
- `reviews` — лог на всяко преглеждане: оценка, време за отговор, увереност.
- `attempts` — отговори по задачи извън SRS: верен/грешен, време, режим.
- `exams` — симулации: изпит, вариант, отговори, точки по части, време по задача, статус (може да се продължи).
- `errors` — тетрадка на грешките: елемент, брой грешки, последна дата, статус „усвоено“.
- `writings` — мои текстове с версии и самооценка по критерии.
- `sessions` — учебни сесии: начало, край, режим, брой елементи.
- `settings` — дати на изпитите, дневни лимити, глас за TTS, тема, свободно време по дни.

## 5. Функционалности

Всеки модул има критерии за готовност (КГ). Ако модулът не покрива КГ, не е готов.

### 5.1 Табло
- Обратно броене до двата изпита; „Днес“ — списък от планировчика (5.8) с прогрес; серия и топлинна карта на активността; топ 5 слаби места с бутон „Тренирай“; бързи бутони: Флашкарти / Практика / Симулация / Писане.
- Екран „За проверка“ с непроверените елементи (3.1) и бутон „Проверено“.
- КГ: на телефон всичко е достъпно без хоризонтално скролване; таблото се зарежда под 1 s при 5000+ карти.

### 5.2 Флашкарти (SRS)
- FSRS с четири оценки: Отново / Трудно / Добре / Лесно. Клавиши 1–4 и интервал; undo на последната оценка.
- Дневни лимити за нови карти и за преговор; режим „Cram“ преди изпит (без график, по тагове); персонализирани сесии по тагове, колоди и трудност.
- Незадължителна оценка на увереността преди отговора (за калибрирането в 5.10).
- TTS бутон на английските карти.
- КГ: unit тестове за планировчика с фиксирани дати; undo работи; сесията се възстановява след затваряне.

### 5.3 Практика (упражнения по тип задача)
- Избор по изпит → тип задача → тема; незабавна обратна връзка с обяснение; „защо другите са грешни“.
- Адаптивност: следващите елементи идват предимно от тагове с ниска точност.
- Смесен режим (interleaving): редува типове задачи и дори двата изпита.
- Сесия от N елемента с обобщение накрая; всяка грешка влиза в тетрадката (5.7).
- КГ: всички типове от 4.1 се рендират и оценяват правилно; оценителите имат тестове (нормализация, множество приети отговори, частични точки за KWT).

### 5.4 Изпитен симулатор
Общо: без обратна връзка до края; маркиране на задачи „за преглед“; навигация по задачи; таймер с предупреждения (30/10/5 мин); автоматично запазване; продължаване след прекъсване; отчет с точки по части, време по задача, списък с грешки и обяснения; всяка грешка влиза в 5.7.

**БЕЛ — пълен вариант по официалния модел.** Провери актуалния модел и примерния тест на МОН за 2027 г. и наподоби реда и вида на задачите.
- 41 задачи, 4 астрономически часа, 100 точки (70 тест + 30 аргументативен текст).
- 22 задачи с избираем отговор, 16 с кратък свободен отговор, 2 с разширен свободен отговор (провери какво точно изискват), 1 задача за аргументативен текст (интерпретативно съчинение или есе).
- Задачите с избираем и кратък отговор се оценяват автоматично. Двете с разширен отговор — самооценка по примерен отговор и критерии. Задача 41 отваря Лабораторията за писане (5.5) с таймер в общото време.
- Генератор на варианти: сглобява вариант от банката по тагове и трудност, така че да покрива същите области като реалния изпит — правопис, пунктуация, граматика, лексика, работа с информационен текст, четене с разбиране на откъс от произведение от програмата, познаване на произведенията, съпоставки.
- Резултат 0–100 и ориентировъчна оценка по официалната скала (провери я).

**CAE — всяка компонента отделно, с реалните времена.** Провери всичко по официалния handbook за C1 Advanced преди да строиш.
- Reading and Use of English: 90 мин, 8 части, 56 въпроса. Част 1 multiple-choice cloze (8, по 1 т.), част 2 open cloze (8, по 1 т.), част 3 word formation (8, по 1 т.), част 4 key word transformations (6, до 2 т.), част 5 multiple choice (6, по 2 т.), част 6 cross-text multiple matching (4, по 2 т.), част 7 gapped text (6, по 2 т.), част 8 multiple matching (10, по 1 т.).
- Writing: 90 мин; част 1 задължително essay (220–260 думи); част 2 избор от letter/email, proposal, report, review (220–260 думи).
- Listening: около 40 мин, 4 части, 30 въпроса; всеки запис се чува два пъти. Част 1 три кратки разговора (6 MC), част 2 sentence completion (8), част 3 MC (6), част 4 multiple matching (10; петима говорители, две задачи). Реализира се с TTS по скриптове (5.6).
- Speaking: 15 мин, 4 части (приблизително: part 1 interview ~2 мин; part 2 long turn ~4 мин общо — 1 мин на кандидат + кратък отговор от другия; part 3 collaborative task ~4 мин; part 4 discussion ~5 мин). Реализира се с таймери, запис и транскрипция (5.6). Партньорът се симулира с примерни реплики (текст + TTS).
- Резултат: процент по компонента и ориентировъчна прогноза по Cambridge English Scale (C1 = 180–199; 200–210 = степен A, ниво C2; 160–179 = сертификат за B2). Обозначи прогнозата ясно като приблизителна — точна таблица за конверсия не е публикувана.

### 5.5 Лаборатория за писане
- Задания: БЕЛ — есе и интерпретативно съчинение по теми от банката; CAE — всички типове от Writing.
- Поток: 1) план (теза + 3 аргумента/точки) с таймер 5–7 мин; 2) писане с таймер и брояч на думи; 3) самооценка по официалните критерии с чеклист; 4) сравнение с примерен текст (анотиран: кое е силно, кое е слабо); 5) запис на версията.
- Критерии БЕЛ (задача 41, 30 т.; провери в актуалния документ на МОН): I. литературни/интерпретативни компетентности (10 т.); II. изграждане на аргументативен текст — теза (0–3), аргументация (0–3), логическа последователност (0–3), композиция: увод, изложение, заключение (0–3); III. езикови норми — лексикална (0–2), граматична (0–2), правописна (0–2), пунктуационна (0–2).
- Критерии CAE: Content, Communicative Achievement, Organisation, Language — по 0–5.
- Банка с фрази по тип текст: свързващи думи, формули за увод и заключение, формален и неформален регистър.
- Бутон „Копирай за обратна връзка“: сглобява текст със заданието, критериите и моя текст и го копира в клипборда, за да го поставя в приложението Claude и да получа оценка по критериите. Това е заместителят на AI оценяване без бекенд.
- История на версиите; графика на обема и времето.
- КГ: броячът на думи е точен за кирилица и латиница; текстът не се губи при затваряне.

### 5.6 Слушане и говорене (CAE)
- Слушане: скриптовете се четат със `speechSynthesis`; различни гласове за различните говорители (от наличните в браузъра; предпочитай en-GB/en-US); темпо 0.8–1.2; режим „изпит“ (два пъти, без пауза) и режим „тренировка“ (пауза, повторение на изречение, транскрипт по изречения); shadowing режим (повтаряш след говорителя).
- Говорене: таймери по части; запис с `MediaRecorder` (пази последните 20 записа); транскрипция със `SpeechRecognition`, когато е налична; статистика: думи в минута, пълнители (um, like, you know), дължина, употреба на целеви фрази; самооценка по критериите Grammatical Resource, Lexical Resource, Discourse Management, Pronunciation, Interactive Communication (0–5); примерни отговори (текст + TTS).
- Произношение: карти за словесно ударение и трудни думи с TTS.
- Резервен вариант: ако няма гласове или разпознаване (напр. ограничения в iOS), приложението показва скрипта и позволява самооценка. Никога не блокира.
- КГ: тествано в Chrome Android, Safari iOS и десктоп Chrome; при липса на API няма грешки в конзолата.

### 5.7 Тетрадка на грешките
- Всяка грешка от практика и симулации влиза автоматично; режим „Преговор на грешките“ с приоритет по честота и давност; елементът излиза от тетрадката след 3 поредни верни отговора в различни дни; графика „по кои тагове греша“.

### 5.8 Планер
- Въвеждам дати на изпитите и свободно време по дни от седмицата (в минути).
- Планировчикът разпределя обратно от датата: седмични цели по области; дневна квота (нови карти, преговор, упражнения, писане); календар на симулациите (напр. пълен БЕЛ вариант на 2 седмици от февруари, CAE компонент всяка седмица).
- Дневният план се преизчислява при изоставане или изпреварване. Показва се на таблото.
- КГ: чиста функция `buildPlan(settings, progress, today)` с тестове.

### 5.9 Аналитика
- Овладяване по произведение, езикова норма, тип задача и тема; тенденция на точността; време за учене; прогноза на FSRS за задържане; „при това темпо до изпита ще покриеш X %“. Диаграмите са прости SVG, без тежки библиотеки.

### 5.10 Иновативни режими (всеки е малък, но реален и завършен)
- „Познай произведението“: цитат → автор и произведение (и обратно); „Познай героя“ по реплика или описание.
- Калибриране на увереността: оценка на увереността преди отговора; точките наказват уверените грешки; графика „увереност срещу точност“.
- Режим „Файнман“: обясняваш произведение, тема или правило в 5 изречения със свои думи → чеклист с ключовите точки, които трябва да присъстват → самопроверка.
- Интерливинг: смесени сесии от двата изпита и от различни типове задачи.
- „Обратен тест“: даден е отговорът, пишеш въпроса.
- Интерактивна времева линия на българската литература (автори, направления, произведения, исторически контекст) с тест по нея.
- Карти на произведенията: mind-map диаграми (SVG, генерирани от данните) — герои, теми, мотиви, композиция, връзки с други произведения — с кликаеми възли към картите.
- Микросесии от 3 минути за телефон; „Сутрешен преговор“ и „Преди сън“ (5 карти + 1 цитат).
- Дневно предизвикателство: фиксиран микс за деня (seed = датата) с резултат.
- Лов на грешки: намери и поправи грешката в изречение на ниво C1 (CAE) или редактирай текста (БЕЛ).
- Речник-детектив (CAE): колокации в контекст; „намери грешната колокация“; word families и регистър.
- Общ тренажор за аргументация (БЕЛ есе ↔ CAE essay): теза, аргументи, свързващи думи, контрааргумент — умение, което носи точки и на двата изпита.
- Експорт към Anki (TSV) като резервен вариант.

## 6. Съдържание — обхват и минимуми

### 6.1 БЕЛ
Първа стъпка (Фаза 2): изтегли официалната учебно-изпитна програма за ДЗИ по БЕЛ от `mon.bg` и запиши списъка с автори и произведения в `content/bel/program.json`. Не генерирай съдържание за произведения извън програмата. Ориентировъчно (провери!): 11. клас — Ботев, Вазов, Алеко Константинов, П. П. Славейков, Яворов, Елин Пелин, Дебелянов; 12. клас — Смирненски, Гео Милев, Далчев, Багряна, Йовков, Вапцаров, Димов, Талев и авторите след 1944 г. по програмата (напр. Радичков, Хайтов, Ивайло Петров — провери точния списък и произведенията).

За всяко произведение:
- „Паспорт“: автор, година/период, жанр, литературно направление, исторически и биографичен контекст.
- Резюме (сюжет, композиция), теми и мотиви, образи и герои, стил и жанрови особености, заглавие и смисъл, връзки и съпоставки с други произведения от програмата (изпитът обича съпоставки).
- Ключови цитати (проверени) с коментар за какво „работят“ в есе или интерпретативно съчинение.
- Типични теми за задача 41 (по 3–5 на произведение) с теза и план на аргументите.
- Минимум: 20 карти (basic + cloze), 10 MCQ, 5 short, 3 cloze от цитати.

Език (минимум 400 елемента общо; обяснението цитира правилото):
- Правописна норма: слято, полуслято и разделно писане; главни и малки букви; променливо я; двойни съгласни; звучни и беззвучни съгласни; о/у; съкращения.
- Пунктуационна норма: запетаи при подчинени изречения, еднородни части, обособени и вметнати части, обръщения и съюзи; пряка реч; тире; двоеточие; кавички.
- Граматична норма: пълен и кратък член; бройна форма; учтива форма; съгласуване; кой/кого, който/когото; деепричастия; местоимения; глаголни времена и залог.
- Лексикална норма: пароними, плеоназми, тавтологии, чуждици, стилово неуместни думи, фразеологизми.
- Редактиране на текст: 30+ текста с по 5–10 грешки.

Работа с текст: 12+ комплекта с информационни текстове (включително по два текста за съпоставка) с въпроси за тема, ключови думи, извличане на информация и отношение между текстовете.

Аргументативен текст: 30+ теми (есе и интерпретативно съчинение) с план; 8+ пълни примерни текста, написани от теб, като поне два са „средни“ с коментар защо не са отлични; официалните критерии за задача 41.

### 6.2 CAE
- Лексика: 1500+ елемента на ниво C1 в контекст — колокации, phrasal verbs, идиоми, word families, свързващи думи, регистър. Карта: дума или израз, изречение, дефиниция на английски, български превод като подсказка, TTS.
- Граматика (300+ елемента): inversion, cleft sentences, emphasis, mixed conditionals, wish/if only, participle clauses, passive with reporting verbs, modals of deduction (past), future in the past, ellipsis and substitution, articles and determiners, relative clauses, hedging, comparison structures.
- Use of English: по 12+ комплекта за части 1–3; 100+ KWT елемента.
- Reading: по 6+ комплекта за части 5–8 (текстове 500–900 думи, различни жанрове, автентичен стил).
- Listening: 4+ пълни комплекта (всичките 4 части) със скриптове за няколко говорители и реалистични дистрактори.
- Writing: essay 15+ задания; letter/email, proposal, report, review — по 5+; примерни текстове с анотации; банка с фрази; скалата за оценяване.
- Speaking: 6+ пълни комплекта за части 1–4 с описания на сцените, банка с въпроси, примерни отговори, полезни фрази.

### 6.3 Общо
- Всеки елемент отговаря на 3.1. Разпределение на трудността приблизително 20/30/30/15/5 % за нива 1–5.
- Първо покрий минимумите равномерно (v1), после увеличавай. Не пиши 1500 думи в една сесия за сметка на качеството — по-добре 300 отлични.
